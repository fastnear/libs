# Crates by FASTNEAR

- [`fastnear-openapi-generator`](/openapi-generator) - Shared helpers for generating checked-in OpenAPI documents from typed service DTOs and Rust-owned operation registries.
- [`fastnear-primitives`](/primitives) - This crate provides the base set of primitives used by other fastnear crates.
- [`fastnear-neardata-fetcher`](/neardata-fetcher) - This crate provides a fetcher to retrieve data from neardata.xyz.
